# 使用 PageNest Companion

本文对应 Companion **1.12.1**；安装包与发行状态以仓库 **Releases** 为准。

## 安装与启用

要求 WordPress 6.0+、PHP 8.0+。

1. 在 仓库页面的 **Releases** 下载发行附件中的 `pagenest-compatibility-版本号.zip`，选择安装包，而非自动生成的 Source code ZIP。
2. 在后台打开 “插件 → 安装插件 → 上传插件”，上传 ZIP，安装并启用。
3. 打开 “设置 → PageNest 设置 → 阅读互动”，选择所需功能。段落评论还需要逐篇文章明确启用；新文章默认关闭。
4. 用不同账号验证公开评论、作者操作、点赞，以及站点现有邮件服务。无需复制数据库。

推荐配合 PageNest · 栖页 使用。评论通知不依赖 PageNest；MathJax、Prism 前端适配和 Materialis Companion 防冲突处理则仅在主题支持 `pagenest-independent-layout` 特性时启用。插件没有 SMTP 配置页面。

## 配置入口、来源与默认行为

日常设置集中在「设置 → PageNest 设置」八个页签。媒体文件夹和媒体质量仍位于「媒体」菜单；独立测速位于「工具 → 页面测速」。主题配色与布局继续使用「外观 → PageNest」。

## 评论通知与邮件服务

审核通过的新留言可通知文章作者，回复可通知原评论者。未审核留言不会触发通知，插件避免本人通知、重复发送及与 WordPress 原生通知重复。已成功发送的通知按评论和收件地址记录；旧版记录继续参与去重。

通知通过 WordPress `wp_mail()` 和站点已有邮件服务发送。本插件默认沿用站点邮件服务；服务器管理员可单独启用 Brevo API 传输。没有历史通知补发或定时重试任务。启用前先确认站点邮件服务可用，再用测试文章与不同收件账号验证留言和回复。内存测试不会实际发信，不能作为邮件投递证明。

私密文章校验收件账号的阅读权限；无权限账号不会收到本插件通知。通知不复制评论正文，只引导收件人回到文章查看。密码保护文章不发送本插件通知。WordPress 原生通知仍遵循 WordPress 自身规则。

## 站内回复通知

在 “设置 → PageNest 设置 → 通知” 启用独立的站内通知模块，默认关闭。PageNest 页眉提供通知铃铛；其他主题可在已有页面加入 `[pagenest_notifications]`，不会自动创建页面或菜单。登录读者的可见页面只加载一次最近通知未读计数，不预取通知标题、作者或链接；计数大于零才显示角标。读者主动打开或点击 “加载通知” 后才加载列表正文，无后台轮询。

普通评论回复仅处理模块启用期间的新提交，接收者是原评论关联的登录账号；待审核回复通过审核后才显示。在同一页签还可单独启用 “新公开段落评论通知文章作者”，此项默认关闭，并要求段落评论功能和对应文章的评论入口已启用。它只通知文章作者，不建立段落回复线程。私人笔记、导入、旧笔记改公开、历史评论、本人评论和编辑已有评论都不会补发通知。两类通知均遵守读者的接收偏好，关闭偏好只影响未来通知，不改变邮件设置或原有通知。

列表合并普通回复与公开段落评论，按通知时间展示最近窗口，每页 10 条、最多 100 条。可切换 “全部” 与 “未读”；筛选只在这个窗口内进行，不是全站历史未读总数。每条可单独 “标为已读”；“本页标为已读” 仅处理当前已载入页面的未读条目，不会标记其他页。操作失败时重新读取列表并提示结果，已成功标记的条目不会回退。

普通回复链接返回原评论，段落评论链接返回原文段落。来源文章或父评论变为私密、密码保护、未审核、删除或身份归属变化时，该通知不再显示；段落评论变为私人、段落关联失效或关闭对应评论功能时同样隐藏。通知仅支持公开文章和页面，不为私密来源放宽权限。

通知列表只保存在当前页面内存，关闭弹窗、隐藏页面或离开页面时清空；返回后需再次主动加载正文。关闭弹窗可保留本页刚由服务端确认的角标计数；页面隐藏、离开或鉴权失败后清除，页面重新可见时独立重取一次计数。计数失败、未知或归零时隐藏角标。账号设置和已读状态通过 WordPress 元数据保存，不使用浏览器持久存储、新表或定时任务。WordPress 原生隐私导出包含接收者的两类通知元数据和偏好；擦除只移除通知元数据并关闭未来接收，不删除原评论、段落评论或私人笔记。再次审核或重复提交不会重建已擦除通知。

## 编辑器、公式与代码高亮

插件保留旧 Markdown 公式保护规则及每篇文章的编辑器选择。在文章编辑页的 “使用的编辑器” 框中勾选 “使用块编辑器”，保存后重新打开文章。该选择基于现有 `use_block_editor` 元数据；未勾选时沿用其他编辑器提供方的选择，不强制安装或提供 Markdown 编辑器。

主题声明 `pagenest-independent-layout` 特性时，插件在文章或页面的单篇视图中从 cdnjs 加载 **MathJax 2.7.7**；如果 `mbb-math` 已入队，则不重复加载。MathJax 不随插件打包，会产生第三方网络请求；站点网络或内容安全策略需要允许该资源。它支持 `$…$`、`\(…\)`、`$$…$$` 与 `\[…\]` 分隔符，跳过代码块等区域。

同一主题条件下，Prism 适配根据当前入队的 autoloader 或 core 依赖 URL 推导 `components/` 目录；无法识别时保留提供方配置。仅注册、未入队的资源不触发配置。非标准目录可通过 [扩展接口](EXTENDING.md) 适配。

旧站适配钩子不构成对任意 Markdown/公式插件组合的兼容承诺。新网站和升级后的站点都应按自己的插件组合验证公式、代码高亮与编辑器保存行为。

## 旧版升级与兼容范围

升级前备份文件和数据库。从 0.4 升级时先停用旧版，再安装并启用目录 `pagenest-compatibility` 中的 `pagenest-compatibility.php`，不要同时启用两份插件。0.5 之后保持该目录和入口名称。

兼容配置的 `mail.sent_meta_keys` 和 `mail.lock_option_prefixes` 只读既有通知标记和锁，合并当前标记以避免重复发送。不清空旧记录。

插件保留 2048 登录提示短代码、旧资源范围函数及 Materialis Companion 迁移期间的防冲突处理，不包含积分规则或数据库重算；OAuth 为独立、默认关闭的可选服务。它保护既有私人笔记并提供公开段落评论。短代码只输出登录提示，不提供成绩记录功能。

## 章节、段落评论和点赞

编辑文章，在 “PageNest 阅读功能” 中选择 “启用” 段落评论并保存，保存动作只为这篇文章创建段落注册表；前台仅读取，不自动为未保存段落生成身份。公开发布须明确确认；旧私人接口要求登录、文章阅读权限与作者身份，未知可见性保持私人。编辑和删除须提供当前 opaque `version`，冲突不会覆盖。公开投影不含私人正文、数量、UUID、源指纹和历史引用；匿名只读。没有 PageNest 主题时使用独立抽屉。

在文章的 “PageNest 阅读功能” 中填写同名系列和非负整数章节顺序。没有排序值时沿用文档顺序；旧站的显式文档列表可保留原有顺序。相对 Markdown 链接由 `link_map` 明确映射至现有文章，只有可读取、未锁定文章才转换；只改渲染 HTML。点赞要求登录、公开可读文章且不是作者本人，按文章串行锁与 InnoDB 事务写记录和计数。历史 provider 只读事件账本；历史读取或事务能力失败时拒绝写入。经验扩展监听 `pagenest_like_recorded($user_id, $post_id, $count)`，点赞不依赖经验插件。

## 显式兼容配置

在服务器 `wp-config.php` 定义 `PAGENEST_COMPATIBILITY_PROFILE_FILE` 指向 Web 根之外的 JSON 文件，限制文件读取权限。插件不搜索上传目录或 URL，不在加载时复制设置。无法读取、未知字段、格式或标识错误会禁用功能并显示管理员提示。

完整 schema 见 [扩展接口](EXTENDING.md)。默认中性键用于新安装；已有数据须先填写旧存储键、路由、主题别名和历史 provider，不清空或重编号记录。

## 后台阅读设置

“设置 → PageNest 设置 → 阅读互动” 仅站点管理员可修改。WordPress 设置侧栏统一保留 “PageNest 设置” 入口；阅读互动、搜索与分享、通知、我的阅读、内容导览、模块诊断、媒体与文件夹、社交登录通过页内顶部导航切换，手机可横向滑动导航。修改提示与保存按钮放在一起；筛选和只读诊断不显示未保存提示。段落评论、章节导航与链接、点赞可以分别停用；关闭只暂停展示/API，不删除记录，也不会停止普通 WordPress 评论通知。

在本页 “系列目录” 填写文章现有的系列名称，按标题选择公开目录页，也可直接填写页面 ID。每行显示关联标题、查看链接或失效提示，保存阅读设置后生效。名称精确匹配，包括大小写和空格；已保存名称只读，清空目录页 ID 可解除关联，新增系列使用末尾空行。目录及上级页面须公开、无密码且层级有效；失效表单或任一无效关联都会拒绝整份目录保存，刷新后检查并重试。服务器配置的关联只读并优先；旧文档可以由服务器显式绑定目录系列，不写回文章，也不改变章节分组。

文章作者或有编辑权限的用户可在 “PageNest 阅读功能” 中设置本篇文章：

- **保持现有**保留原先的启用状态；只有选择 “启用” 或 “停用” 才保存新的状态。启用并保存会刷新本篇段落注册表，不会扫描其他文章。
- **系列名称**把同名文章归为一组，最多 100 个字符；主动清空可退出旧系列。
- **章节顺序**为 0 至 1000000 的整数，留空使用文档顺序。非法输入会拒绝整个配置更新。

修订、自动保存和未通过 nonce/编辑权限检查的请求不会保存阅读设置。正文修改可能改变段落身份；已有引用快照和私人可见性继续保留。旧兼容键只读，新设置优先，因此可安全保留旧值与显式空值。

### 维护整组章节顺序

在阅读互动页签下方的 “系列章节” 选择现有系列，查看章节标题、当前顺序及缺失或重复的提示。这里只列出已发布或私人文章中、当前管理员可读取并编辑的章节；不会把草稿自动发布，也不会按目录关系猜测成员。

1. 用上移／下移按钮调整位置，整组会依次编号；也可直接修改各章的非负整数顺序。
2. 点击预览，检查按实际前台规则排列后的结果。预览不会保存；相同数值仍按原有文档及文章 ID 规则排序。 缺失值与数字混排时沿用旧的回退比较，不自动重编号；完整填写数字后再预览，可明确本次要保存的顺序。
3. 确认后保存章节顺序。保存只更新该组文章的中性顺序字段，不改系列名称、正文、来源、目录绑定、评论或私人笔记。关闭 JavaScript 时仍可输入数值、预览及保存。

成员、旧顺序或权限在此期间变化时，提交会被拒绝，仍有权限的输入保留供核对；刷新后重新预览再保存。由服务器显式 `series_order` 控制的章节只读，只有目录由服务器关联的普通系列仍可调整。需要改变系列归属或清空单篇顺序时，使用文章编辑页的阅读功能。

维护视图采用有限读取：全站最多 500 篇带系列键的候选文章、相关章节元数据键合计 2500 条记录，每组最多 100 章。超过范围、存在不可编辑成员或存储表不支持事务时拒绝整组保存，避免把不完整列表当成完整系列。

## 浏览计数

“设置 → PageNest 设置 → 阅读互动” 可明确启用默认关闭的浏览计数，选择统计人群、机器人排除及纯文本显示模板。`%VIEW_COUNT%` 替换为格式化的次数；HTML 不会作为标记输出。重复页面加载会再次计数，读取计数不会计数。预览、后台、私人文章和密码锁定文章不计数；解锁后的公开文章可计数。

仅支持 `WP_CACHE=false` 的 PHP 页面渲染，缓存启用时停计并在后台提示，不提供 AJAX 或 REST 替代路径。停用保留数据，启用不会扫描历史文章、发布内容或发放经验。

## 社交账号与恢复邮箱

启用社交服务后，在自己的 “个人资料” 中管理连接。连接、解除连接或发送邮箱验证前，先输入当前密码确认身份；只有社交登录的账号可用已连接的供应商确认。确认仅对当前浏览器会话生效，十分钟后需要重新确认。

建议在解除最后一个社交登录前设置恢复邮箱：先通过 WordPress 保存可收信的邮箱（如提示确认邮箱变更，先完成该步骤），再点击 “发送验证邮件”，登录发起验证的账号并打开邮件链接，点击 “确认邮箱”。链接三十分钟有效。旧邮箱不会自动视为已验证，变更邮箱后需要重新验证；没有其他可用连接或已验证邮箱时，系统拒绝解绑，不删除账号。

首次使用未连接的社交账号时，可明确选择创建新本站账号，或先登录已有账号后到资料页重新授权连接。选择创建后会进入资料表单：用户名、邮箱必填，昵称选填并预填第三方昵称，留空使用用户名。重名、邮箱已用或格式错误会在页面提示，可修正后重试；邮箱填入不等于验证完成，账号创建后仍须在个人资料验证恢复邮箱。系统不会按昵称或相同邮箱合并账号。若提示身份已属于其他账号，请使用原账号登录，或联系管理员核实。

删除 WordPress 用户后，插件同步清理属于该用户的社交身份索引与解绑记录。若清理因并发锁或数据库错误未完成，下次登录／绑定会核实原用户已不存在后再释放残留归属；存活用户的绑定不会因此转移。

## 管理第三方登录配置

管理员可从 “设置 → PageNest 设置 → 社交登录” 逐家配置 QQ、百度、微博、GitHub、Google 与微信网站应用。先填写应用 ID、密钥和 HTTPS 同源回调地址，再明确启用该提供者；社交登录总开关和允许新用户注册分别控制。关闭注册不影响已绑定账号登录。开启某个提供者不会迁移或合并历史账号。

服务器配置作为默认来源，首次打开页面不会将凭据复制进数据库。每家单独保存，只覆盖所选提供者；“恢复服务器配置” 移除该项后台覆盖。页面标示当前配置来源。邮件、验证码、分享与历史映射仍由既有服务器配置管理。

密钥字段始终为空，仅提示是否已配置；留空保留当前有效密钥。更换应用 ID 时须填写对应新密钥，不能沿用其他应用的密钥；需要清除时须明确选择并关闭该提供者。后台保存的凭据位于不自动加载的私有 WordPress option，不向 REST 或访客公开，但会随数据库备份，备份应按凭据保护。

保存需要管理员权限、POST 与 nonce；错误不会回显密钥，整次更新校验失败时保留原配置。服务器 profile 损坏不会被后台覆盖掩盖；后台记录损坏只停用社交服务，可由管理员恢复继承后重新配置。存在服务器管理策略时先协调来源，避免恢复继承重新启用服务器原先开启的提供者。

个人资料中的 “社交账号” 分为安全确认、恢复邮箱与登录方式卡片。已连接的当前应用提供确认身份和解除连接；未连接的应用提供连接按钮。历史连接单独标注 “当前不可用于登录”，不会自动迁移或删除。近期身份确认显示有效截止时间，过期后操作仍需重新确认。

确认身份、连接、解绑及邮箱验证完成后，会返回个人资料显示操作结果。提示只属于当前登录会话，短期有效且仅展示一次；失败不会展示第三方错误或凭据。邮件提示 “已提交发送” 不代表送达。邮箱已经验证时不重复显示发送按钮，更改邮箱后需重新验证。

## 新增社交供应商

GitHub、Google 和微信网站应用均需管理员自行创建并控制对应应用。默认关闭；管理员可在插件的社交登录设置中填写接入参数，也可使用受限服务器配置。每家分别启用。按钮出现或模拟测试通过不代表真实授权成功。

| 提供者 | 应用类型与准备                                                                                                              | 身份范围                                    |
| ------ | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| GitHub | [Developer settings → OAuth Apps](https://github.com/settings/developers)，使用 OAuth App                                   | `read:user` 基本用户资料，不请求仓库权限    |
| Google | [Google Auth Platform](https://console.cloud.google.com/auth/overview)，创建 Web application 客户端；Testing 时添加测试用户 | `openid profile`，不请求 Gmail 或 Drive     |
| 微信   | [微信开放平台](https://open.weixin.qq.com/) 创建网站应用，完成主体资格／应用审核并取得微信登录权限                          | 网站扫码 `snsapi_login`，不是公众号网页授权 |

在 `services.social.providers` 中按名称配置 `enabled`、`client_id`、`client_secret`、`redirect_uri`；不要向聊天或工单发送凭据。默认回调格式为 `https://example.com/wp-admin/admin-post.php?action=pagenest_social_callback&provider=github`，另两家分别将最后的值替换为 `google`、`wechat`；用实际站点地址替换示例域名。控制台与服务器配置的回调须完全一致。微信控制台按网站应用要求登记授权回调域，并使用同域 HTTPS 回调。不要把任一新供应商设置为历史应用回退。

应用准备完毕、代码发布且配置启用后，由应用所有者在无痕窗口测试：拒绝授权、首次创建时填写资料、已有绑定回到原账号、登录后重新确认身份与绑定／解绑、退出后再次登录。测试过程中保留一个已验证的恢复方式，不发送完整回调 URL 或令牌。Google Testing 与微信审核限制由各自控制台决定；跨供应商相同邮箱不会合并账号。

## 可选媒体展示

插件提供默认关闭的媒体兼容模块。在迁移管理员验证画廊映射后，通过 “设置 → PageNest 设置 → 媒体与文件夹” 启用。它接管没有其他负责人注册的 `[wpmfgallery]`、`[wpmfpdf]` 及对应旧区块；保留正文中的原始标记，不自动改写文章。

画廊保留配置的图片集合、排序方式、列数、间距、自动轮播和灯箱。轮播使用缓动滑动与首尾循环，箭头叠放在两侧；窄屏显示一列并支持手势；悬停、键盘焦点、暂停按钮和减少动态效果偏好可以暂停自动切换。没有 JavaScript 时显示图片链接。PDF 查看器支持翻页、缩放、搜索和打印，下方保留原文件链接。查看器来自随包提供的 PDF.js，资源不依赖旧媒体插件或 CDN。自有查看器的工具栏随窄框换行，保留翻页、缩放、更多菜单和下载；查看器配色跟随页面，PDF 内容保持原样。

可选的 `library_taxonomy` 配置为媒体组织插件的附件分类法后，媒体库网格上方会显示文件夹卡片、路径导航和返回上一级按钮。点击文件夹沿用当前搜索、媒体类型和排序；新建／改名后可点击 “刷新文件夹”。默认仅提供浏览入口，目录管理仍由原插件负责。管理员可在 “设置 → PageNest 设置 → 媒体与文件夹” 启用自有媒体文件夹；新安装使用独立分类法，原站接管必须由迁移管理员保留已有分类法配置，并先停用原管理插件。存在原负责人时不会覆盖。关闭配置即隐藏导航，数据保留。

自有模式下，在 “媒体 → 媒体文件夹” 创建、改名、调整父目录或删除目录；删除目录不会删除附件。在媒体网格选择附件后点击 “分配文件夹”，或在列表使用同名批量操作，也可从附件详情进入分配页。一次最多 200 个附件，只增加或移除勾选的归属，其他目录不变。保存后刷新已打开的媒体窗口。网格、列表和文章编辑器的媒体选择器均支持目录与未分类筛选。仅管理员管理目录；分配需要上传权限及每个附件的编辑权限。

此模块不是完整媒体库或画廊编辑器。文件上传、图片编辑和多媒体详情继续由 WordPress 管理；既有画廊编辑器的全部高级功能不在兼容范围内。迁移管理员配置的固定图片与来源文件夹取并集，固定图片不会因移出文件夹而消失；要删除固定成员需要更新映射。已有随机排序保持随机，不承诺每次加载的顺序完全相同。

启用前检查附件权限、文件链接、目录层级、多文件夹归属和每篇旧媒体文章；不要仅按文件夹名称导入，同名的不同父目录必须分开。模块不会搬动文件、生成缩略图、迁移文件夹或删除旧插件数据。旧展示程序必须先在隔离环境停用验证；不能把本模块启用当作允许卸载旧插件。

完整中性配置格式见[扩展接口](EXTENDING.md#媒体展示配置)。

## 内容发现与基础 SEO

在 “设置 → PageNest 设置 → 搜索与分享” 分别启用搜索建议和元信息。模块默认关闭；升级不自动开启，不创建搜索索引表、计划任务、第三方服务或内容副本。

配合 PageNest 1.1.0，顶栏与搜索页提供公开内容建议和文章／页面／工具筛选；至少两个字符，每次最多八条建议，提交后仍使用 WordPress 分页搜索。建议接口 `pagenest/v1/discovery` 无需登录且禁止共享缓存；只返回公开标题与链接，不返回正文。私人／草稿／密码文章即使调用者是管理员也不进入建议；工具还必须具有有效提供者、稳定页面绑定、公开访问和列表资格。启用时旧搜索链接也使用这些过滤；工具注册表故障时暂不列出页面，普通文章仍可搜索。

SEO 提供描述、Open Graph、Twitter 卡片和 JSON-LD。文章描述使用手写摘要，缺失时使用本站描述／副标题，不执行短代码或提取正文；特色图优先于后台默认分享图，再回退站点 Logo。没有图片时使用文字卡片。密码内容、私人内容、预览、搜索／404、分页后续页及禁止搜索引擎索引的网站不输出这些元信息。

WordPress 仍负责标题、canonical、robots 和原生 XML 站点地图；本模块不重写 URL，不提交搜索引擎、不保证收录或排名。识别常见 SEO 插件后停止输出，其他提供者可通过 `pagenest_companion_seo_external_owner` 返回 true 接管。自定义元信息前应检查是否已有重复的 head 输出。

更换主题不删除配置；关闭模块也保留设置与文章数据。网页缓存如不监听 WordPress 选项变化，须由站点维护者失效相关页面后再检查。

“账号阅读” 是同一设置页中的独立开关，默认关闭，目前仅支持单站点 WordPress；多站点网络保留原有本机阅读和本人记录功能，不启用账号同步。管理员启用后，登录读者先点击 “加载账号阅读”，再勾选同意并启用；启用只保存同意状态，不会上传本机历史。其他设备登录同一账号后也需主动加载，才会看到账号中的公开文章和阅读位置。

手动同步时点击 “合并本机与账号记录”，要求本机记忆已开启且浏览器存储可用。同一文章使用时间较新的阅读位置，“稍后读” 标记取两端保留的结果，合并后最多保留最近 100 篇。此操作不包含评论、私人笔记或阅读设置。未同意本机存储时仍可查看账号列表并直接继续阅读，不会把账号记录写进浏览器。另一设备更新了账号记录时，旧版本操作会被拒绝；先刷新、核对，再重新操作。账号已保存但本机写入失败时，会分别提示两端结果，不自动重试上传。

“管理账号记录” 可逐项移除、清空账号列表或撤回同意。撤回同时清空账号记录并停止阅读位置同步；独立阅读偏好须在其设置中单独撤回。这些操作不删除本机记录，之后再次明确合并可能把本机尚保留的条目加入账号。关闭本机记忆也不会清空账号记录。管理员暂停账号同步后，已有账号状态的读者仍可从精简入口撤回；若整个 “我的阅读” 入口被关闭，可通过 WordPress 原生个人数据擦除流程清除。

账号只持久保存文章 ID、阅读时间、有效标题锚点与稍后读标记，不保存标题、链接或正文。显示和同步时重新核对来源公开性；转为私人、密码保护、删除或失去公开访问的文章不再显示，下一次合并时移除相应条目。只读加载不清理数据库中的旧记录；读者也可主动清空或撤回。已加载的账号列表仅留页面内存，切换页签、关闭面板、隐藏或离开页面、登录失效时清除。原生隐私导出包含本人的原始记录与同意状态，擦除保留用于拒绝旧请求的最小关闭状态，原评论、笔记和本机记录不受影响。

### 自动阅读与阅读偏好

1.12.0 起提供以下功能。管理员的账号阅读总开关仍默认关闭，自动位置与阅读偏好也分别默认关闭；本机记录与手动合并继续可用。

在 “账号阅读” 展开同步设置并主动加载后，可分别选择在本设备启用自动阅读位置或阅读偏好。自动位置要求先同意账号阅读并开启本机记忆；只保存同意之后当前公开文章的新位置与稍后读改动，不上传旧本机历史。旧历史仍须点击 “合并本机与账号记录”。请求只在页面可见时有界触发，不后台轮询、离线排队或在离开页面时补传；失败后本机阅读继续，账号同步暂停，需要重新加载并明确确认。

移除或清空账号记录、撤回账号阅读以及关闭自动位置，都会暂停其他设备的自动位置；各设备须重新确认，旧设备不会把已删除记录自动传回。原本机记录保留。

偏好应用需要支持阅读偏好协议的主题，例如 PageNest 1.8.0。旧主题或未提供阅读设置的页面会明确显示无法应用，仍可撤回偏好同意；自动阅读位置不依赖该协议。切换账号不会继承另一账号的设备绑定。

脱敏 JSON，只含版本、固定模块状态／来源类型和固定边界说明，不含网址、路径、账号、凭据或用户正文。
RSS 使用 WordPress 原生订阅地址；PageNest 主题注册原生 feed links，并在分类归档显示该分类 RSS 入口；本版本没有自动订阅邮件
或在未征得同意时上传阅读记录。账号阅读、自动位置和阅读偏好分别征求同意，旧本机历史仍须手动合并；邮件订阅尚未提供。

## 媒体质量

在「媒体 → 媒体质量」按缺少 alt、图注或两项都缺少筛选，每页最多 20 张图片。
每个附件分别填写文本，可单独保存或显式提交本页，每项有独立结果；单项提交后其他未保存输入保留在表单中。
不提供给全部图片灌入同一 alt 的入口，也不删除、移动文件或改变附件作者、父级、文件夹和来源。
提交需要上传能力、每个附件的读取／编辑权限与 nonce；保存时在事务中锁定附件及 alt 元数据，
刷新缓存后核对表单旧值，经 WordPress API 写入。旧值冲突时该附件两个字段均不改写。

「检查已保存正文中的引用」每次最多扫描 20 篇文章／页面，只检查当前用户可读取、大小不超过 1 MB 的已保存正文。
具备文章和页面的读取私人、编辑他人权限者可检查全站；其他上传作者的查询仅包含本人文章和页面，
他人未授权正文不影响其计数和分页。
识别原生区块、支持的画廊／PDF 短代码附件 ID、图片类名及附件原图／已登记尺寸 URL；
不执行短代码、渲染动态区块、读取文件系统或请求外部 URL。区块最多 500 个、嵌套最多 30 层。
页面显示本页已查、跳过和下一页入口；模板、站外和未检查正文可能仍有引用，不能以「未找到」判断附件未使用。

## WordPress 个人数据导出

管理员在 WordPress「工具 → 导出个人数据」按请求邮箱处理。Companion 的三个导出器始终注册，
功能开关关闭后仍可导出已有记录；以该邮箱对应的用户为目标，不使用执行任务的管理员身份。
每页最多处理 20 条记录（另取 1 条判断下一页），按稳定 ID 排序；无对应邮箱用户时直接结束。

段落评论与私人笔记使用兼容配置中的记录类型、数据键及作者 ID，保留旧默认私人和失联目标记录，
只导出本人记录 ID、UUID、目标 ID、文档身份、段落锚点、已保存引用、文本、可见性、创建／更新时间
及重新关联时保留的前次引用和锚点。
不渲染正文，也不随目标文章的权限输出标题或链接。点赞只导出自有记录中的本人点赞时间与文章 ID；
不含他人的点赞列表，也不查询外部旧积分／事件表。社交绑定只含供应商和本人 subject 的 SHA-256 摘要，
不含应用信息、令牌、验证挑战、密钥或账号所有权映射，不代表第三方账号全部个人资料。
原生隐私导出 JSON 的 value 按 WordPress 契约保存 HTML 安全文本；显示时解码一次可还原字面字符；反斜杠使用数字实体，避免核心多页元数据合并时丢失。
需要原始笔记数据时可使用已有笔记 JSON 导出。无效兼容配置或存储失败会返回错误，不宣称导出完成。

本功能仅导出，不删除记录、解绑账号或迁移数据。外部旧积分记录由其原组件负责；浏览器阅读历史只在本机，
不属于服务器隐私导出，读者可在本机阅读入口自行清除。
